# 🔐 Password Generator

A simple and user-friendly Password Generator built using **Python Flask, HTML, CSS, and JavaScript**.

## 🚀 Features

* Generate random passwords
* Choose the number of letters
* Choose the number of numbers
* Choose the number of symbols
* Copy generated password
* Simple and responsive user interface

## 🛠️ Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript

## 📁 Project Structure

```text
password-generator/
│
├── app.py
├── requirements.txt
│
├── templates/
│   └── index.html
│
└── static/
    ├── style.css
    └── script.js
```

## ▶️ How to Run

### 1. Install Flask

```bash
pip install -r requirements.txt
```

### 2. Run the application

```bash
python app.py
```

### 3. Open in Browser

```text
http://127.0.0.1:5000
```

## 💡 How It Works

1. Enter the number of letters you want.
2. Enter the number of numbers you want.
3. Enter the number of symbols you want.
4. Click **Generate Password**.
5. The Python backend generates the password.
6. Click **Copy Password** to copy it.
